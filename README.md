### 🎯 About Me

I design and ship production-grade web applications and AI-powered systems. End-to-end TypeScript is my home turf — from polished React/Next.js interfaces, to NestJS service layers, to multi-tenant data models, and increasingly to autonomous agents that automate real-world workflows.

- 🛠️ Currently building CRM platforms, real-time messaging systems, and agentic AI workflows
- 🤖 Architecting LLM agents with **LangChain** and **LangGraph** for production use cases
- 📈 Focused on clean architecture, strong typing, and measurable performance
- 📚 Always picking up new patterns, frameworks, and paradigms
